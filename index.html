Student Gap Analyser: System Architecture & Implementation

An automated competency evaluation platform designed to systematically identify curriculum-to-industry voids and construct actionable upskilling roadmaps for undergraduate engineers.

STAGE 01

Candidate Profiling

Ingests student-selected programming languages, frameworks, and self-reported project milestones via validated schema.

STAGE 02

Role Taxonomy Mapping

Matches declared competencies against dynamic industry competency vectors (Backend, Full Stack, SDE Core).

STAGE 03

Gap Differential Engine

Calculates readiness coefficients and ranks missing technical dependencies using Python algorithmic evaluation.

STAGE 04

Curated Roadmap

Outputs structured JSON payloads containing step-by-step remedial projects and internship preparation milestones.

FastAPI API Endpoint Design

from pydantic import BaseModel
from typing import List, Dict

app = FastAPI(title="Student Gap Analyser API", version="1.0.0")

class StudentProfile(BaseModel):

    target_role: str
    current_skills: List[str]

@app.post("/api/v1/analyze-gap")
async def analyze_skill_gap(profile: StudentProfile) -> Dict:

    result = evaluate_competency_vector(
        skills=profile.current_skills,
